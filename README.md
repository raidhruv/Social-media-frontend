# SocialMedia Frontend

A production-grade frontend for a modern social media platform built with React and Vite.

## Tech Stack

- React
- React Router
- Axios
- Vite
- JavaScript
- FastAPI Backend
- JWT Authentication
- Refresh Token Rotation

## Architecture

Feature-based architecture

src/
├── app/
├── features/
├── shared/
├── assets/
├── styles/
└── ...
